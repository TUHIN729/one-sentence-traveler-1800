One sentence, built from what a person from 1800 already knows — a road, a letter, a book, a library — that explains the modern internet to a traveler who has just stepped out of that year: a road of light joining houses the world over, carrying more letters, books, and songs than all the world's libraries hold, straight to your door in the blink of an eye.

## Run it

```sh
node main.ts
```

It writes the sentence to `/output/entry.txt`.
